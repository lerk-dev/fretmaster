FretMaster 统计得分方案验证实例

本文档说明优化后的得分方案、IP 记录字段，以及验证步骤。

1. 得分方案对比

维度优化前优化后
记录频率除 pitch_finding 外，每答对一题就 record 一次所有 tab 统一"会话级"记录，会话结束才记一次
score未传时硬编码 100round(correct/total * 100)，未答题记 0
accuracy同上（0-100）同 score（0-100）
duration全局共享 sessionStartTime，切 tab 会乱会话开始到结束的实际秒数
切 tab 处理无切到非练习 tab 自动结束当前会话并记录

2. 验证用例

用例 1：找音练习 - 答对 8 题，答错 2 题

输入：isPlaying true→false，score = {correct: 8, total: 10}，会话时长 120 秒
预期记录：exercise_type="找音练习", score=80, accuracy=80, duration=120, client_ip="<访问设备 IP>"
注：不再硬编码 100 分

用例 2：音程练习 - 答对 5 题，答错 1 题

输入：完成 6 个音程后停止练习，score = {correct: 5, total: 6}，时长 90 秒
预期记录：exercise_type="音程练习", score=83, accuracy=83, duration=90
注：之前每答对一题就记一次，现在整轮会话只记一次

用例 3：音阶练习 - 答对 3 题，答错 0 题

输入：完成 3 个音阶后停止，score = {correct: 3, total: 3}，时长 45 秒
预期记录：exercise_type="音阶练习", score=100, accuracy=100, duration=45

用例 4：和弦练习 - 答对 4 题，答错 2 题

输入：完成 6 个和弦后停止，score = {correct: 4, total: 6}，时长 60 秒
预期记录：exercise_type="和弦练习", score=67, accuracy=67, duration=60

用例 5：和弦进行 - 完成整轮后继续，最终答对 2 轮、答错 1 个和弦

输入：停止时 score = {correct: 9, total: 10}（每轮 5 个和弦），时长 180 秒
预期记录：exercise_type="和弦进行", score=90, accuracy=90, duration=180
注：之前每完成一轮就记一次，现在整次会话只记一次

用例 6：开始后立即停止（未答题）

输入：isPlaying true→false，score = {correct: 0, total: 0}
预期：不记录（sessionScore.total > 0 判断）

用例 7：切 tab 练习中切走

输入：找音练习答对 3 题后切到音程 tab
预期：找音会话自动结束并记录 score=100（3/3），然后音程会话开始

3. IP 记录字段

环境client_ip 来源示例值
Web（路由器访问）CGI 环境变量 $REMOTE_ADDR，支持 X-Forwarded-For192.168.123.45
Tauri（Windows 桌面）固定字符串local

注：IP 在后台静默记录，前端 stats-panel 不展示。可通过 SQLite 查询 SELECT client_ip, COUNT(*) FROM practice_records GROUP BY client_ip 查看多设备使用情况。

4. 数据库表结构

-- Web 端 practice_records 表
CREATE TABLE practice_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id TEXT NOT NULL,
    exercise_type TEXT NOT NULL,
    score INTEGER NOT NULL,        -- 0-100
    duration INTEGER NOT NULL,     -- 秒
    accuracy REAL,                 -- 0-100
    notes TEXT,
    client_ip TEXT,                -- 新增：客户端 IP
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tauri 端 practice_stats 表
CREATE TABLE practice_stats (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    exercise_type TEXT NOT NULL,
    exercise_detail TEXT,
    score INTEGER NOT NULL,
    duration INTEGER NOT NULL,
    accuracy REAL,
    notes TEXT,
    client_ip TEXT,                -- 新增：客户端 IP（固定为 "local"）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

5. 验证步骤

  1. 访问 http://192.168.123.2/
  2. 进入"找音练习"tab，答对 5 题、答错 5 题，停止
  3. 查看"统计"面板：应有 1 条记录，得分 50，准确率 50%
  4. SSH 到路由器：sqlite3 /www/fretmaster/data/practice.db "SELECT exercise_type, score, accuracy, duration, client_ip FROM practice_records;"
  5. 确认 client_ip 字段为访问设备的 IP（如 192.168.x.x）
  6. 切换到音程练习 tab，答对 3 题、答错 1 题，停止
  7. 统计面板应有 2 条记录，第二条得分 75
